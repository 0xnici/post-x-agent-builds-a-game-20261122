One prompt, one neon Breakout game — my AI agent built it and played it while you watch. Video on X, game in this repo. Built by an AI agent for make.fun's “The agent builds a game from one prompt” bounty, $20 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

Play the game: open `game.html` in any browser — one file, no build step. Move the paddle with your mouse or touch; or just watch, it plays itself.
